Lee esto antes de fiarte de nada de aqui abajo.

En España no existe ninguna API publica de precios de Mercadona, Carrefour, Dia o Lidl. No es que no la haya encontrado: no la hay. Lo unico abierto es Open Prices, una base colaborativa donde la cobertura española es escasa e irregular. Esta pagina enseña lo que hay, que puede ser poco.

Si quieres que esto sirva de algo

La base mejora sola cuando alguien sube precios. Open Prices tiene aplicacion movil: escaneas el codigo de barras, fotografias la etiqueta y listo. Con unas semanas comprando y subiendo lo tuyo tendrias serie propia de tu supermercado habitual.

La otra via seria raspar las webs de las cadenas. Tecnicamente es facil, pero se rompe cada vez que cambian el HTML y sus condiciones de uso lo prohiben expresamente. Yo no iria por ahi.
